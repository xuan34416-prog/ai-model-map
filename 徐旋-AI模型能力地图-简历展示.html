01 / PROJECT OVERVIEW

一个面向决策的模型资料系统

不是又一个聊天窗口，而是帮助团队理解模型差异、复核选择依据、连接业务场景的长期资产。

635模型记录
65厂商覆盖
715静态页面
224管线自检项

项目价值

面对模型发布快、名称多、评测口径不一的问题，建立统一的模型资料入口。每个结论都尽量保留数据来源、指标口径和缺失状态，避免把“没有数据”误写成“能力弱”。

可比较能力、成本、上下文和评测按同一结构呈现。
可解释排行榜和推荐结果能追溯到字段与来源。
可维护通过自动同步和校验闸门降低人工维护成本。

我的切入点

结合电气工程、半导体厂务和电力电子业务背景，把通用模型数据进一步连接到企业知识、设备运维和技术方案等真实流程。

输入公开元数据、第三方评测、价格与上下文。
加工字段仲裁、来源标记、异常检测、能力归一。
输出模型地图、选型建议、场景化应用入口。
02 / SYSTEM DESIGN

从数据到判断的三层链路

采用静态站点与确定性数据管线，减少部署复杂度；把合规、质量和可解释性放在展示之前。

LAYER 01

多源采集

接入模型元数据、公开评测、价格、上下文和开源许可等信息，并保留字段级来源。

LAYER 02

仲裁与校验

按字段选择可信来源，检查数量骤降、单位异常、重复榜单和被拦截数据，失败时保留旧快照。

LAYER 03

产品化呈现

生成排行榜、时间线、模型对比、搜索索引和场景化入口，让复杂资料可被快速理解。
